## 3. Thesis

1. **Easing cycle = risk-on:** Fed done → 75bps cut → EM inflow. JCI already bottomed Oct-23 (capitulation). Banks benefit from NIM stabilization + coverage adequacy → can grow loans without provisioning spike.
2. **Election + stimulus = consumption boost:** Rice handout + El Nino cash + campaign spending → consumer staples (ICBP) and property (CTRA + PPN DTP VAT cut) benefit 1H24. Data traffic spikes 2 quarters pre-election → telco/tower volume.
3. **Selective sector rotation:** Property at 75% discount to NAV (vs 69% 5Y) → re-rating on VAT stimulus IDR 3.2T; tower low tenancy = growth runway (MTEL largest in SEA, 58% outside Java, DER <1); DRMA consolidation + new factory = auto parts alpha; coal/metal face slump → NEUTRAL, stock-pick only (cost leaders).
4. **Holdco/regulatory overhangs are entry:** UNVR downgraded (expensive, competitive pressure), RALS SELL (discretionary shift to staples), coal regulatory (RKAB quotas) caps upside — avoid beta, buy quality.

- **Index:** `JCI = EPS 2024 × 14.0×`. Table p25: Bear 524.3→7,300 / Base 547.4→7,600 / Bull 574.8→8,000. 5Y avg P/E 22.1 shown as anchor, fair 14× is **below +1 SD** → conservative. Earnings growth 3.6%/8.6%/13.6% scenarios.
- **Stock-level:** Each sector section gives TP with method implied:
  - Banks: **GGM / P/BV vs ROE** (like Samuel BBCA Daily — P/BV 0.9–4.6, ROE 20%+)
  - Telco infra: **EV/EBITDA** (TOWR 1,310, MTEL 875, TBIG 2,040) + tenancy/fiber KPIs
  - Property: **Discount to NAV** (75% vs 69% 5Y → RNAV-based TP, CTRA 1,400)
  - Consumer: **PER** (ICBP 13,000 at 20× ROE)
- **Bands:** **JCI 5-year P/E band** (p25, Fig 73: +2 SD / +1 SD / Mean / -1 / -2) — identical to Maybank's -2 SD call and MTEL's PBV/EV bands. This IS `calc_bands()`.
- **No DCF printed** — strategy is top-down multiple only (DCFs in company notes).
